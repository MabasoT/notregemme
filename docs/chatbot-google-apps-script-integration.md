# Notre Gemme Chatbot — Google Apps Script Integration Guide

This guide explains how to connect the **NotreGemmeChatbot** to a Google Apps Script backend so that bookings, product enquiries and pre-orders are automatically logged to a Google Sheet and trigger email/WhatsApp notifications.

---

## Overview

```
Browser (Next.js chatbot)
        │
                │  POST JSON  { intent, message, name?, contact? }
                        ▼
                        Google Apps Script Web App  (doPost)
                                │
                                        ├── Writes row to Google Sheet  (bookings / enquiries tab)
                                                └── Sends email notification   (MailApp or Gmail)
                                                ```

                                                ---

                                                ## Step 1 — Create a Google Sheet

                                                1. Go to [sheets.google.com](https://sheets.google.com) and create a new spreadsheet.
                                                2. Name it **Notre Gemme — Chatbot Logs**.
                                                3. Create two sheets (tabs):
                                                   - **Bookings** — columns: `Timestamp | Name | Contact | Size | Notes`
                                                      - **Enquiries** — columns: `Timestamp | Intent | Message`

                                                      ---

                                                      ## Step 2 — Open the Apps Script Editor

                                                      1. In the Google Sheet click **Extensions → Apps Script**.
                                                      2. Delete the default `myFunction()` stub.
                                                      3. Paste the script below.

                                                      ---

                                                      ## Step 3 — Paste the Apps Script

                                                      ```javascript
                                                      // ============================================================
                                                      //  Notre Gemme — Chatbot Google Apps Script Backend
                                                      //  Deploy as: Web App  |  Execute as: Me  |  Access: Anyone
                                                      // ============================================================

                                                      const SPREADSHEET_ID = "PASTE_YOUR_SPREADSHEET_ID_HERE";
                                                      const NOTIFICATION_EMAIL = "hello@notregemmestudios.co.za"; // change to your email

                                                      // ── Entry point ──────────────────────────────────────────────
                                                      function doPost(e) {
                                                        try {
                                                            const data = JSON.parse(e.postData.contents);
                                                                const intent = (data.intent || "enquiry").toLowerCase();

                                                                    if (intent === "booking") {
                                                                          handleBooking(data);
                                                                              } else {
                                                                                    handleEnquiry(data);
                                                                                        }

                                                                                            return ContentService
                                                                                                  .createTextOutput(JSON.stringify({ ok: true }))
                                                                                                        .setMimeType(ContentService.MimeType.JSON);
                                                                                                        
                                                                                                          } catch (err) {
                                                                                                              return ContentService
                                                                                                                    .createTextOutput(JSON.stringify({ ok: false, error: err.message }))
                                                                                                                          .setMimeType(ContentService.MimeType.JSON);
                                                                                                                            }
                                                                                                                            }
                                                                                                                            
                                                                                                                            // ── Booking handler ──────────────────────────────────────────
                                                                                                                            function handleBooking(data) {
                                                                                                                              const ss    = SpreadsheetApp.openById(SPREADSHEET_ID);
                                                                                                                                const sheet = ss.getSheetByName("Bookings");
                                                                                                                                
                                                                                                                                  sheet.appendRow([
                                                                                                                                      new Date(),
                                                                                                                                          data.name    || "",
                                                                                                                                              data.contact || "",
                                                                                                                                                  data.size    || "",
                                                                                                                                                      data.notes   || "",
                                                                                                                                                        ]);
                                                                                                                                                        
                                                                                                                                                          MailApp.sendEmail({
                                                                                                                                                              to:      NOTIFICATION_EMAIL,
                                                                                                                                                                  subject: "📅 New Size Fitting Booking — Notre Gemme",
                                                                                                                                                                      body:
                                                                                                                                                                            `A size fitting has been requested.\n\n` +
                                                                                                                                                                                  `Name:    ${data.name    || "N/A"}\n` +
                                                                                                                                                                                        `Contact: ${data.contact || "N/A"}\n` +
                                                                                                                                                                                              `Size:    ${data.size    || "N/A"}\n` +
                                                                                                                                                                                                    `Notes:   ${data.notes   || "N/A"}\n\n` +
                                                                                                                                                                                                          `Timestamp: ${new Date()}`,
                                                                                                                                                                                                            });
                                                                                                                                                                                                            }
                                                                                                                                                                                                            
                                                                                                                                                                                                            // ── Enquiry handler ──────────────────────────────────────────
                                                                                                                                                                                                            function handleEnquiry(data) {
                                                                                                                                                                                                              const ss    = SpreadsheetApp.openById(SPREADSHEET_ID);
                                                                                                                                                                                                                const sheet = ss.getSheetByName("Enquiries");
                                                                                                                                                                                                                
                                                                                                                                                                                                                  sheet.appendRow([
                                                                                                                                                                                                                      new Date(),
                                                                                                                                                                                                                          data.intent  || "general",
                                                                                                                                                                                                                              data.message || "",
                                                                                                                                                                                                                                ]);
                                                                                                                                                                                                                                }
                                                                                                                                                                                                                                ```
                                                                                                                                                                                                                                
                                                                                                                                                                                                                                > **Replace** `PASTE_YOUR_SPREADSHEET_ID_HERE` with the ID from your Sheet URL:
                                                                                                                                                                                                                                > `https://docs.google.com/spreadsheets/d/**THIS_PART**/edit`
                                                                                                                                                                                                                                
                                                                                                                                                                                                                                ---
                                                                                                                                                                                                                                
                                                                                                                                                                                                                                ## Step 4 — Deploy as a Web App
                                                                                                                                                                                                                                
                                                                                                                                                                                                                                1. Click **Deploy → New deployment**.
                                                                                                                                                                                                                                2. Click the ⚙️ gear icon and select **Web app**.
                                                                                                                                                                                                                                3. Set:
                                                                                                                                                                                                                                   - **Description**: `Notre Gemme Chatbot API`
                                                                                                                                                                                                                                      - **Execute as**: `Me`
                                                                                                                                                                                                                                         - **Who has access**: `Anyone`
                                                                                                                                                                                                                                         4. Click **Deploy** → copy the **Web app URL** (looks like `https://script.google.com/macros/s/XXXX/exec`).
                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                         ---
                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                         ## Step 5 — Add the Web App URL to the Next.js project
                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                         Create or update `lib/site-config.ts` to add:
                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                         ```ts
                                                                                                                                                                                                                                         export const chatbotConfig = {
                                                                                                                                                                                                                                           appsScriptUrl: process.env.NEXT_PUBLIC_APPS_SCRIPT_URL ?? "",
                                                                                                                                                                                                                                           };
                                                                                                                                                                                                                                           ```
                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                           Add to your `.env.local` (and Vercel environment variables):
                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                           ```
                                                                                                                                                                                                                                           NEXT_PUBLIC_APPS_SCRIPT_URL=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
                                                                                                                                                                                                                                           ```
                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                           ---
                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                           ## Step 6 — Update NotreGemmeChatbot to POST bookings
                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                           In `components/NotreGemmeChatbot.tsx`, add a `submitBooking` helper and call it when the user triggers the booking flow:
                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                           ```ts
                                                                                                                                                                                                                                           async function submitBooking(payload: {
                                                                                                                                                                                                                                             name: string;
                                                                                                                                                                                                                                               contact: string;
                                                                                                                                                                                                                                                 size?: string;
                                                                                                                                                                                                                                                   notes?: string;
                                                                                                                                                                                                                                                   }) {
                                                                                                                                                                                                                                                     const url = process.env.NEXT_PUBLIC_APPS_SCRIPT_URL;
                                                                                                                                                                                                                                                       if (!url) return;
                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                         await fetch(url, {
                                                                                                                                                                                                                                                             method: "POST",
                                                                                                                                                                                                                                                                 body: JSON.stringify({ intent: "booking", ...payload }),
                                                                                                                                                                                                                                                                   });
                                                                                                                                                                                                                                                                   }
                                                                                                                                                                                                                                                                   ```
                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                   Call `submitBooking(...)` after the user confirms their booking details in the chat flow.
                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                   ---
                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                   ## Step 7 — Test the integration
                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                   You can test the Apps Script endpoint directly with `curl`:
                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                   ```bash
                                                                                                                                                                                                                                                                   curl -L -X POST "YOUR_WEB_APP_URL" \
                                                                                                                                                                                                                                                                     -H "Content-Type: application/json" \
                                                                                                                                                                                                                                                                       -d '{"intent":"booking","name":"Test User","contact":"0821234567","size":"M","notes":"Hoodie fitting"}'
                                                                                                                                                                                                                                                                       ```
                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                       You should see:
                                                                                                                                                                                                                                                                       - A new row in the **Bookings** sheet
                                                                                                                                                                                                                                                                       - An email notification to `NOTIFICATION_EMAIL`

                                                                                                                                                                                                                                                                       ## Chatbot Booking Flow (recommended UX)
                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                       Add these steps inside `NotreGemmeChatbot.tsx` to guide users through a booking:
                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                       ```
                                                                                                                                                                                                                                                                       User says: "I want a fitting" or "Book sizing"
                                                                                                                                                                                                                                                                         → Bot: "Great! What's your name?"
                                                                                                                                                                                                                                                                           → User types name
                                                                                                                                                                                                                                                                             → Bot: "And your WhatsApp number?"
                                                                                                                                                                                                                                                                               → User types number
                                                                                                                                                                                                                                                                                 → Bot: "Which item(s) would you like to try? (Hoodie, T-Shirt, Cap…)"
                                                                                                                                                                                                                                                                                   → User picks item
                                                                                                                                                                                                                                                                                     → Bot: "Got it! We'll reach out within 24 hours to confirm your fitting time. 🙌"
                                                                                                                                                                                                                                                                                       → [POST to Apps Script with intent: "booking"]
                                                                                                                                                                                                                                                                                       ```

                                                                                                                                                                                                                                                                                       ## Security Notes
                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                       - The Apps Script Web App is deployed with **"Anyone"** access to allow unauthenticated POST requests from the browser.
                                                                                                                                                                                                                                                                                       - Do **not** store sensitive customer data (e.g. ID numbers, payment info) in the chat or Sheet.
                                                                                                                                                                                                                                                                                       - For production, consider adding a simple shared secret header check:
                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                       ```javascript
                                                                                                                                                                                                                                                                                       // In doPost — add at the top:
                                                                                                                                                                                                                                                                                       const SECRET = PropertiesService.getScriptProperties().getProperty("CHATBOT_SECRET");
                                                                                                                                                                                                                                                                                       if (e.parameter.secret !== SECRET) {
                                                                                                                                                                                                                                                                                         return ContentService.createTextOutput(JSON.stringify({ ok: false, error: "Unauthorized" }))
                                                                                                                                                                                                                                                                                             .setMimeType(ContentService.MimeType.JSON);
                                                                                                                                                                                                                                                                                             }
                                                                                                                                                                                                                                                                                             ```
                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                             Set the property in **Project Settings → Script Properties**: `CHATBOT_SECRET = your-secret-token`
                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                             Then in your Next.js `fetch` call, append `?secret=your-secret-token` to the URL.

                                                                                                                                                                                                                                                                                             ## Troubleshooting
                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                             | Issue | Fix |
                                                                                                                                                                                                                                                                                             |---|---|
                                                                                                                                                                                                                                                                                             | `doPost` not firing | Re-deploy after every script change |
                                                                                                                                                                                                                                                                                             | CORS errors | Apps Script Web App handles CORS automatically — make sure you use `-L` (follow redirects) |
                                                                                                                                                                                                                                                                                             | Email not sending | Check Gmail quota (100 emails/day on free accounts). Switch to `GmailApp` for higher limits. |
                                                                                                                                                                                                                                                                                             | Sheet not found | Make sure tab names match exactly: `Bookings` and `Enquiries` |
